# 我的工作方式

这是用户自己写的规则。任务里另外交代了的，以任务为准；仓库自己的 AGENTS.md / CLAUDE.md 里有约定的，也照着做。

下面每份参考都按需读，用不上的不用看。用哪个模型、有哪些仓库这类值是任务面板的「设置」，
不在这里：要用到时，派活的消息里会写给你。

| 参考 | 什么时候看 |
|---|---|
| [references/task.md](references/task.md) | 你是任务面板派出去的 worker 时：一轮结束时怎么说、等别人（同事回话、job 跑完）怎么等、你开的会话来问问题时怎么办 |
| [references/activity.md](references/activity.md) | 做任务面板任务时：怎么跟我说话、结论写在哪 |
| [references/secretary.md](references/secretary.md) | 你是我的秘书（Superagent）时：怎么跟我说话、什么时候打扰我、简报怎么写 |
| [references/compact.md](references/compact.md) | 压缩秘书的对话时：摘要里留什么（这份是交给压缩的，不用你照着做） |
| [references/dispatch.md](references/dispatch.md) | 你是我的秘书、在派活时：外面来的消息接不接、怎么派 |
| [references/routing.md](references/routing.md) | 派活的时候：怎么挑仓库，什么时候换更强或更便宜的模型 |
| [references/deliver.md](references/deliver.md) | 改完代码、要交付的时候：开 MR 还是直推，做完怎么说 |
| [references/mr.md](references/mr.md) | 开了 MR 之后：怎么盯着它、review 意见 / 流水线 / 冲突怎么处理、谁来合、合并之后做什么 |
| [references/proactive.md](references/proactive.md) | Superagent 判断「不是找我的」事要不要主动接的时候 |
| [references/memory.md](references/memory.md) | 我告诉你、纠正你、回答你的话里有对这个仓库以后都适用的（走不走 MR、谁来合、发布找谁批）：要不要记、怎么记 |
| [references/human.md](references/human.md) | 有一步得我亲手做的时候（点授权、建账号、在后台开开关、交密码） |
