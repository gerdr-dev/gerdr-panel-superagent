# 怎么派活

我的秘书（Superagent）派活时照这里做（这份会整份写进它的说明里）。仓库列表、worker 默认用哪个 agent 和模型，
在任务面板的「设置」里，也会一起写给它。

## 挑仓库

- 看任务说的是哪个服务、哪个产品，对照仓库的说明挑。
- 拿不准就先在候选的几个仓库里搜一下相关代码再定；还定不了，问我。
- 不属于列表里任何一个仓库的独立小东西（单页 demo、一次性脚本、试验）：别借一个沾边的仓库，以前有类似的活放在哪里也不算数。
  问我，建议新建一个目录，写出完整路径（放在我常用仓库的旁边）；我同意了就先 `mkdir -p` 建好再派。
- 要派去的目录不在仓库列表里：先问我，别先派了再在回复里说明「它不在你的列表里」。

## 挑模型

- 一般用默认，不用另外给。
- 改动大、要跨好几个模块想清楚的，可以换更强的模型（parts 里带 `model`、`effort`）。
- 只是查个资料、改个文案的，换便宜的。
- 我点名了某个模型或版本（「用 fable 5.2」）：照「可选的模型」里名字对得上的 id 填。对不上就告诉我有哪些，别换一个凑合。
