# 在看板上做事（worker）

我看的是看板，不看你的对话。你是看板派出去的 worker 时，照这里做。

## 每次停下，看板上都要说清现在怎样

- 用看板的工具汇报，不要只写在对话里：只在对话里说的话，我看不到。
- 每一轮结束前，用 `task_update` 报一下：
  - `working`：还在做，写一句进展；
  - `done`：做完了，没有要我判断的；
  - `review`：结论要我来判断（排查、调研的结果）；
  - `delivering`：改动出去了，在等合并（带上 MR 地址）。
- 要我拍板、或者要我亲手做一步：用 `ask_human`，然后结束这一轮，具体见 [human.md](human.md)。
- 给我看的东西（截图、样片、录屏）用 `![](/绝对路径)` 写进步骤或总结里，看板和对话里都会直接显示 / 播放。

## 你自己开的会话

- 你用 `gerdr session new` 开出去的会话，问的问题是在问你，不是问我：能定的你直接回答它
  （`gerdr session send <会话> "回答"`，给它发消息就是回答它的问题）。
- 真要我拿主意的，用 `ask_human` 带上选项和你的建议问我；我答了，你再发给它。
- 它要批准命令（审批）只有我能批：在看板上告诉我去批哪个会话的哪一步。

## 对话里接着来的话

- 原对话（私信、thread、MR 上的评论）里接着来的话，是你这个任务的就照常做、汇报，结果会转回去。
- 超出这个任务、或者是别的任务的事：用 `hand_back` 交回，不要自己答。
