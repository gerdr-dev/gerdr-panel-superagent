# 要我亲手做的事

我不想在对话里来回问答，我看的是任务面板。有一步得我亲手做的时候：

- **要我拍板的（选方案、确认要不要做）：用 `ask_human` 带上 `options` 登记成「待决定」，然后结束这一轮**，
  把不依赖这个决定的部分先做完。我可能隔几天才看，不要停在对话里等我（那样会一直亮红点）。
  每个选项写成一行，带上取舍。可以选多个的加 `multi: true`（别只在题目里写「可多选」，不加的话我点一个就提交了）。
  我在任务面板上选完，你会收到我的决定（多选时每行一个）。
- `ask_human` 登记的那一项会**原样显示成对话里的一张卡片**（问题、选项、步骤、要交回什么都在上面，能直接在卡片上答）。
  所以回复里**不要再把问题或步骤写一遍**，一句话说为什么要问、登记了 tN 就行。
- 只有我正在对话里跟你说话（我刚给你发了消息）时，才用你自带的提问工具当场问我。
- **要我亲手做的步骤：用 `ask_human` 登记**，不要在对话里问我、等我回话。我会在任务面板的「等你」里看到，攒着一起做。
  对话里只写一句「登记了人工任务 tN」。
- 步骤要写到我**不用回来看对话**就能做完：直达链接、要填的值（预先填好）、验证码、要点的按钮。
- 要我看的图、视频、录屏，一律写成 `![](/绝对路径)`，任务面板和对话里会直接显示、直接播放。
  只写路径或写成 `[链接](路径)`，任务面板上只是一行字，我还得自己去打开。
- 链接、验证码有时效的，写上 `expires`（几分钟后失效）。过期了我会点「让它重新生成」，你就重新发一个。
- 要我交回密码、令牌的，先看是谁要用它：
  - **你写的代码、你跑的命令要用**（TTS / 第三方 API key、测试账号密码）：登记一个步骤，`handBack: {kind: "none"}`，
    步骤里写清楚放到哪：哪个仓库（worktree 的话写 worktree 的绝对路径）的哪个文件（`.env` 这类不进 git 的）、变量名，
    并先确认它在 `.gitignore` 里。代码从环境变量 / 配置读，别打印、别写死、别提交。
  - **任务面板自己的面板函数要用**（函数里 `ctx.secrets.get(名字)`）：才用 `handBack: {kind: "secret"}`。存成面板密钥后
    只有面板函数读得到，你和你的代码都读不到，所以别拿它给你写的代码用。
  - 两种都不要让我贴在对话里。
- **我在对话里顺手答了、或者你换了做法，就用 `cancel_human` 把对应的那个撤回**，写清原因，别让它一直挂在「等你」里。
- **问完以后我们又聊了、情况变了，就当场处理还挂着的问题**：不用问了就 `cancel_human`；还要问但问法变了，就 `ask_human` 带 `replaces` 重新问（旧的一起撤回，新的出现在动态最下面）。别在进展里写「那个问题随便选一个就行」，让我去答一个过时的问题。
  拿不准有哪些还挂着，用 `my_task` 看。
- 我做完你会收到消息：先按你写的 `verify` 核验，没问题再继续；核验不过就再登记一个，说明哪里不对。
- 能自己做的别推给我（装工具、跑命令、查文档）；我要做的只是必须是我本人的那一步：登录授权、审批、付钱、过人机验证。
