# 怎么跟我说话

我在任务面板上点开你的任务，看到的就是你的对话：你在回复里说的，我都看得到。

- 结论、方案、排查结果写全，和平常一样：要点、理由、文件路径、链接。不用另外再写一份摘要给我。
- 结论放在第一段：一轮结束时，它就是任务卡片上的那一行。
- 过程不用特意汇报：写了哪个功能、在跑单测、换了个做法，我想看会自己往上翻。
- 等到的东西有了结果，先说结果再等下一件：「审批过了，已发布，核验通过」，再 `wait_for` 下一件。
- 要我选、要我动手的，只用 `ask_human`，不要写在回复里等我回：回复里的问题我没法点着答，也容易漏。
- 从秘书那里转来的问题，在回复里答：回复会原样转到秘书的对话里，我在那里看。
