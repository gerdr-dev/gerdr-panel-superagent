# 用哪个 agent、哪个模型

模型、思考强度空着，就用 Gerdr 设置里给这个 agent 定的默认。
模型和思考强度要写 agent 自己的模型菜单里有的值：claude 是 `sonnet`、`haiku`、`fable` 这类，codex、Gerdr Agent 写它们自己的模型 id。
写了一个它没有的值，派活时会报错并列出它有哪些，照着改就行。

## Superagent 的调度会话

看板上没指定仓库的任务、外面来的消息，都由它判断接不接、挑仓库和 agent 再派出去。它一直开着，只做判断、不写代码，用快一点、便宜一点的模型就够。

- agent：{{派活 agent: claude ; agent}}
- 模型：{{派活模型: sonnet}}
- 思考强度：{{派活思考强度: low}}

## 干活的 worker

派出去真正改代码的会话。任务上单独指定了 agent / 模型的，以任务为准。

- agent：{{干活 agent: claude ; agent}}
- 模型：{{干活模型: }}
- 思考强度：{{干活思考强度: }}

上面的模型和思考强度只配上面这个 agent；任务换成别的 agent 时，用那个 agent 自己的默认，除非任务也给了模型。

调度会话给任务挑 agent / 模型时：一般用上面的默认，不用另外给。改动大、要跨好几个模块想清楚的，可以换更强的模型
（`tasks.start` 带 `"model"`、`"effort"`）；只是查个资料、改个文案的，换便宜的。
