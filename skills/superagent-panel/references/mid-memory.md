# 中期记忆：眼下的事和人

中期记忆记的是**眼下正在发生、跟谁有关**的事：谁在等什么、我替哪个任务去问了谁、谁最近在跟我对接什么、
一件进行中的事有了什么新进展。它让后来的 agent 能把一条消息、一个人和已有的任务联系起来。
比如我在自己的私信里问老王什么时候发版（为了 t12），老王的回答到了秘书那里：秘书查中期记忆看到
「老王：t12 在等他把 X 服务 发到 prod」，就知道该转给 t12。

用 `note` 工具记、改、删；查用 `gerdr panel run memory.mid`（可带 `{"q":"词 词"}`）。
在「设置 → 记忆 → 中期」里我能看到、能改。

## 和长期记忆的区别

- 长期记忆（[memory.md](memory.md)）是**不常变的规矩**，会被当成规则照做，所以只记我说过或确认过的。
- 中期记忆是**眼下的事实**，只是帮你把事情连起来的线索：你自己观察到的、外面消息里别人说的都可以记，不用问我。
- 长期记忆一直有效；中期记忆几小时到几周，事情了结就删。
- 长期记忆按仓库；中期记忆按人、按事，有对应的任务就挂上任务。

## 什么时候记

- 你开始等某个人或某件事：等谁、等他做什么（「老王：t12 在等他把 X 服务 发到 prod」）。
- 查出一件事的关键人物：谁在推进、谁能拍板、问题是谁提的。
- 外面的消息带来一件进行中的事的进展（「老王说今天会发」）：更新原来那条，不是再加一条。
- 我告诉你我刚去问了谁、在跟谁对接什么（「我问了老王发版的事」「小李这两周在跟我对接 Y 项目」）。
- 一条消息你没接，但它说的是一件正在进行的事、以后可能还要对上：记一句它说了什么、和哪件事有关。

不记：任务自己的进展细节（在任务的对话里）、密码 token、你的猜测、跟谁都没关系的寒暄。

## 怎么写

- 一条一句，人或事开头，写全名或我平时的叫法和项目名：「老王（Wang Lei）：今天会把 X 服务 发到 prod，发了 t12 要让提问的同事复测」。
  后来的 agent 是拿人名、关键词来对的，只写「他说今天发」对不上。
- 有对应的任务就带 `task`；worker 不写也会挂到自己的任务上。
- 会过时又不随任务结束的，带 `until`（YYYY-MM-DD）。
- 有了新进展用 `replaces` 改掉原来那条；事情了结了（发了、答了、不做了）就只给 `replaces`、`text` 留空，删掉。

## 什么时候查

- 秘书：一条消息不在任何任务的对话里、但像是回话、进展、给我的信息时，判不接之前先查（见 [dispatch.md](dispatch.md)）。
- worker：要找某个人、或者收到一条看不出来龙去脉的消息时。

## 整理

每天会把任务已结束、已过期的条目交给秘书（[整理]）：了结的删掉；还有用的改成最新的；
其实是不常变的规矩（「X 服务 发 prod 找老王批」）就照 [memory.md](memory.md) 问我确认后记进长期记忆，再删掉这条。
