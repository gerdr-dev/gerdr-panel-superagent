# Let it go：按我的策略决定问不问我

我在面板的「Let it go」页设了几套策略，每套先选管哪些仓库，再定生效时间、哪些事可以不问我、哪些人仍要我过目、给你们的说明。
几套可以同时生效、各管各的仓库；同一个仓库被几套管着时排在前面的为准。有的策略放开很多，有的什么都不放（比如下班后一律问我）。
没有策略管着的仓库，什么都照常问我。

- **现在是哪套、放开了什么**：秘书看消息开头的 [Let it go] 那一段；worker 看 `my_task` 的 `letgo`（没有这一项就是没放开你这边的事，照常问我）。
  worker 那一项只说管你这个仓库的那一套；秘书那一段列出每套管哪些仓库。里面有策略的说明（红线、拿不准时怎么定），照它做。
- **工具会自己照策略处理**：
  - `ask_human` 带选项、策略让你自己拍板时，不会出卡片，而是让你带上 `pick`（你选的）和 `why`（一句理由）再调一次，记在任务上，我回来能看、能推翻。然后照选的接着做。
  - `reply_message` 在策略放开发消息时直接发出去；对方在策略的「仍要你过目的人」里，照样出卡片等我发。
  - 秘书的 `decide` accept：每一份的仓库都由放开了「外面来的活」的策略管着，就直接派出去，否则进待办。
- 只有我本人能做的（登录、2FA、审批、付钱）不管哪套策略都照常登记给我，同时把不依赖它的部分全做完。
- 主动找别的人（不在任务跟的对话里）：策略放开了发消息、对方不在「仍要你过目的人」里，可以以我的名义直接发；否则交给我（`ask_human` 写好要发的话）。
